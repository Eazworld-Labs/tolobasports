# source-assets

Original, full-size files that the site does not serve. They were moved here from
`public/` so they no longer ship in the build (and `source-assets/` is in
`.dockerignore`, so they stay out of the Docker image). Nothing was deleted: use these
to regenerate the optimized copies in `public/optimized/` (for example with
`npx sharp-cli`), or to find a photo again.

The folder layout mirrors `public/`, so `source-assets/images/pc1.jpeg` used to be
`public/images/pc1.jpeg`. The gallery data (`src/features/Gallery/gallery.js`) keeps an
`original` path for each gallery photo.
